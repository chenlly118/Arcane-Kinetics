# Arcane Kinetics 0.3.0 — First public beta / 首个公开测试版

Minecraft **1.21.1** · **NeoForge 21.1.251+** · **Java 21**

奥术工程首次公开测试，保留内部版本号 0.3.0。

- 机械学派与 14 个法术，将战斗、采矿、加工和应力驱动结合。
- 聚魔盆、魔化置物台、法术感应器、奥术施法装置与奥术反应装置。
- 卷轴印刷、Create 传送带／置物台法术加工和序列装配。
- 5～19 格边长黑洞反应器、法力和稳定质管理、应力输出及失稳事故。
- 工程师手册、魔化扳手、奥术曲柄、容器与材料；手绘动态核心材质。
- 中英文界面、可选 JEI 展示和 10 个 Ponder 场景，修复演示管道及聚魔盆内腔渲染。
- 聚魔盆采用独立手绘的深灰金属／黄铜护角／紫色内衬纹理与开放盆体模型。
- 鼓风熔炼的气流粉尘及附加火焰／熔岩粒子数量提高至原来的三倍。

**安装：** 两端安装相同版本；需要 Create 6.0.9、铁魔法 1.21.1-3.16.3、Curios 9.5.1、GeckoLib 4.9.3、Iron's Lib 2.2.0、Player Animator 2.0.4。JEI 可选。

**边界：** 尚无完整远程真人联机、大型工厂长测及全部第三方法术验收。黑洞反应器事故会破坏世界。部分材料生产配方属于原整合包。升级前备份世界，在测试世界熟悉设备。

First public beta, retaining version 0.3.0: the mechanical school and 14 spells; spell-powered machines and scroll printing; Create depot, belt and sequenced-assembly processing; a multiblock black-hole kinetic generator; mechanical equipment, animated core artwork, bilingual localization and 10 Ponder tutorials.

Fan Smelting now emits three times as many airflow dust and extra flame/lava particles.

Install on both sides with the dependencies above. Remote multiplayer acceptance, factory endurance and exhaustive third-party spell compatibility remain unverified. Reactor accidents can damage worlds; some material recipes remain pack-specific. Back up worlds before upgrading.

CurseForge, GitHub and Modrinth contain the same main JAR; its checksum is provided in `SHA256SUMS.txt`. Only approved official releases are intended for distribution.

Project renamed to Arcane Kinetics (奥术动力学). This is the existing 0.3.0 binary, so the in-game name may still appear as Arcane Engineering. Updated in-game branding will ship in a future release.

项目现名奥术动力学。本文件与此前 GitHub／Modrinth 发布的 0.3.0 完全相同，游戏内仍可能显示原名称；新的游戏内名称和图标会随之后的版本发布。
