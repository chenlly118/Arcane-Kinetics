# Arcane Kinetics · 奥术动力学

Mechanical magic meets Create automation on **Minecraft 1.21.1 / NeoForge**.

- A mechanical school with **14 spells** for combat, mining, processing and kinetic power.
- Focusing Basins, Enchanted Depots, Spell Sensors and automatic spell emitters.
- Scroll printing and upgrades, a Firework Reactor and paired Portal Funnels for transferring items across dimensions.
- A multiblock black-hole reactor supplying Create stress capacity, with stabilization and accident mechanics.
- An Engineer's Handbook, a dual-mode Enchanted Wrench and Create Ponder tutorials.
- English and Simplified Chinese localization; optional JEI recipe displays.

**Requirements:** Java 21, Minecraft 1.21.1, NeoForge 21.1.251+, Create 6.0.9 and Iron's Spells 'n Spellbooks 1.21.1-3.16.3. Install Curios 9.5.1, GeckoLib 4.9.3, Iron's Lib 2.2.0 and Player Animator 2.0.4 for the same game/loader. Install this addon on both client and server. See the version dependency list for checked files.

**0.5.0 Beta** adds optional integrations with Create: Diesel Generators (fuel, distillation and ink fermentation) and Create: Wizardry (shared fluids and Arcane Plate). See the [full release notes](https://github.com/chenlly118/Arcane-Kinetics/blob/main/release/notes/0.5.0.md).

Reactor accidents can damage worlds; keep backups and learn the Ponder instructions in a test world.

Modpack inclusion of official releases is allowed. Original code is MIT; source and third-party notices are in the [official repository](https://github.com/chenlly118/Arcane-Kinetics).

奥术动力学将机械动力与铁魔法结合：机械学派与 14 个法术、法术驱动加工、自动施法、卷轴印刷与升级、烟花反应装置、跨维度传送门漏斗，以及提供应力的黑洞反应器。包含中英文界面和思索教程，支持可选 JEI 配方展示。
