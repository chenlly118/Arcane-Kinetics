# Arcane Kinetics · 奥术动力学

Mechanical magic meets Create automation on **Minecraft 1.21.1 / NeoForge**.

- A mechanical school with **14 spells** for combat, mining, processing and kinetic power.
- Focusing Basins, Enchanted Depots, Spell Sensors and automatic spell emitters.
- Scroll printing with templates, school materials, ink and paper.
- A multiblock black-hole reactor supplying Create stress capacity, with stabilization and accident mechanics.
- An Engineer's Handbook, mechanical equipment, animated reactor cores and **10 Ponder scenes**.
- English and Simplified Chinese localization; optional JEI recipe displays.

**Requirements:** Java 21, Minecraft 1.21.1, NeoForge 21.1.251+, Create 6.0.9 and Iron's Spells 'n Spellbooks 1.21.1-3.16.3. Install Curios 9.5.1, GeckoLib 4.9.3, Iron's Lib 2.2.0 and Player Animator 2.0.4 for the same game/loader. Install this addon on both client and server. The checked dependency versions are listed above; select Minecraft 1.21.1 files for the correct loader when installing manually.

**0.3.0 is a beta.** Large factory endurance, remote multiplayer acceptance and every third-party spell have not all been tested. Reactor accidents can damage worlds; keep backups and learn the Ponder instructions in a test world. Some Liquid Divine Soul and Arcane Mechanism production recipes remain specific to the original modpack.

The project is now named **Arcane Kinetics** (奥术动力学). The updated in-game name and icon are in source and will ship in a future version; the existing 0.3.0 release is retained.

Modpack inclusion of official releases is allowed. Original code is MIT; source and third-party notices are in the [official repository](https://github.com/chenlly118/Arcane-Kinetics).
